O Student Planner não é apenas um app, é um organismo em constante evolução técnica. Abaixo você encontra os marcos concluídos e o que estamos preparando para as próximas versões.

Concluído

Student Planner v0.0.0-v1.0.5

Implementação da base do projeto, mockups, telas, recursos gráficos, funcionalidades, lógica, Etc.

Base Sólida e Android 17

Implementação de Window Size Classes para suporte a telas grandes, migração de bibliotecas de data e licenciamento Apache 2.0.

Migração completa do Manual DI para Dagger Hilt, visando desacoplamento e facilidade na implementação de testes automatizados.

Implementação de JUnit 5 para Repositories e ViewModels, além de testes de UI com Compose Test Rule para garantir regressão zero.
